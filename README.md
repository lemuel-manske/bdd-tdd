# bdd-tdd

Projeto que explora integração entre BDD e TDD com foco em testes unitários.

O projeto foi desenvolvido como atividade de estudo na faculdade, disciplina de Testes de Software,
onde foi implementado um sistema simples que simula uma videoteca, com foco no aluguel de filmes.

## Compilar e rodar testes

O projeto utiliza o [Maven](https://maven.apache.org/) como ferramenta de build e gerenciamento de dependências. Para compilar o projeto e rodar os testes, siga os passos abaixo:

1. Certifique-se de ter o Maven instalado em sua máquina. Você pode verificar a instalação executando o comando `mvn -v` no terminal.

2. Navegue até o diretório raiz do projeto onde o arquivo `pom.xml` está localizado.

3. Execute o seguinte comando para compilar o projeto e rodar os testes:
   ```
   mvn clean test
   ```
